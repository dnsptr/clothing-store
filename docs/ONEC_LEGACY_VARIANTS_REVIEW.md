# Разбор старых вариантов каталога

Дата: 24.11.2026. Источники: исходный импорт таблицы и полный пакет 1С из 21 товара.

Для 14 SKU заданы точечные соответствия конкретным ID предложений 1С в
`src/lib/onec/legacy-migrations.ts`. Это не глобальный словарь синонимов:
неизвестный SKU, изменившееся название или конфликтующая привязка блокируют
перенос. Другие характеристики с тем же названием не объединяются и получают
отдельные варианты. Существующие ID, SKU и отображаемые подписи сохраняются;
исходные цвет и размер 1С записываются в отдельные поля metadata.

## Оставленный вариант

`MM-1351-OS-15` — **тёмно шоколадный, ONE SIZE** — остаётся без привязки по
решению владельца проекта. В 1С есть два ID «шоколадный», но это не доказательство
соответствия тёмному оттенку. Его цена и существующие настройки доступности
этим этапом не меняются; он не считается синхронизированным с 1С. Перед запуском
автоматического учёта остатков нужно отдельно решить его продажу и привязку.

Нельзя включать общее правило перестановки цветов: в пакете 1С есть разные ID
для сочетаний с обратным порядком компонентов. Подтверждение относится только
к четырём строкам таблицы выше.

## Результат применения

Все 14 точечных привязок применены на сервере в составе обновления остальных
20 товаров. Сохранены исходные ID и SKU старых вариантов. Создан 71 дополнительный
вариант с отдельными ID 1С, обновлены 150 существующих. В полном ассортименте
21 товара — 232 привязанных варианта и один оставленный без привязки.
Повторный расчёт не предлагает новых вариантов и обновлений. Остатки этим
действием не импортировались; данные оплаты, доставки и заказов не менялись.
