# Обмен согласованного ассортимента с 1С

## Источники данных

- 1С: актуальные розничные цены, характеристики (цвет/размер), остатки по складам.
- Админка сайта: фотографии, описания, состав, уход, документы, категории и коллекции.
- Исходная таблица: граница ассортимента, а не актуальный источник цен и наличия.

Различие цены 1С и сайта не является ошибкой 1С. Цена характеристики в 1С
имеет приоритет над старой ценой таблицы. Цена родительского предложения не
подменяет цену варианта. Разные ID характеристик не объединяются автоматически,
даже если названия отличаются только регистром или дефисом.

## Настройка в УНФ

В существующей настройке интеграции откройте **Товары → Выгрузка**.

1. Оставьте выгрузку товаров и предложений включённой.
2. Выберите вид цены **Розничная цена**.
3. Включите **Разбивать остатки по складам**.
4. Отключите присоединённые файлы и ограничение «только товары с изображениями».
   Фотографии остаются под управлением сайта.
5. В строке основного каталога откройте **Отбор**.
6. Замените условие «Номенклатура равно [1916]» условием **В списке** и
   выберите карточки всех 21 артикулов ниже. В списке должны быть ссылки на
   номенклатуру, а не просто текст с номерами артикулов. Если в этом диалоге
   недоступен выбор списка, пришлите его скриншот: названия элементов зависят
   от настроек формы и прав пользователя.
7. Заказы оставьте выключенными. Автоматическое расписание пока не включайте.
8. Сохраните настройку и выполните **Синхронизация данных → Выполнить полный
   обмен данными (все данные)**. «Все данные» означает данные внутри отбора,
   а не всю номенклатуру базы.

## Проверка на сайте

В разделе **Интеграции и обмен** выберите каталог и предложения из одного
полного обмена и постройте отчёт. Ожидаемое покрытие: **21 из 21**. Если 1С
передаст посторонние артикулы, они исключаются из обработки; отсутствующие
артикулы показываются отдельно. Отсутствие в файле не удаляет товар с сайта.

Подтверждены три целевых магазина: Говорово (108811), Принц Плаза (117574),
Авеню (119571). Подтверждённые соответствия в 1С:

| Магазин | Склад 1С | ID склада 1С |
| --- | --- | --- |
| Говорово | Мосмарт | `26b6c04c-4ac9-11f1-9646-e45be2b6c48c` |
| Принц Плаза | Принц плаза | `5b5f9977-a9c2-11f0-a596-101f742cfdb3` |
| Авеню | Авеню | `72f2ca93-a9c6-11f0-a596-101f742cfdb3` |

Соответствие Говорово → Мосмарт подтверждено владельцем проекта 24.11.2026.
Все три склада присутствуют в полученном полном пакете 21 товара.
Разные ID характеристик оставляем отдельными
вариантами, без объединения остатков; это решение подтверждено владельцем проекта.

Текущий обработчик принимает и проверяет XML, а отчёт сопоставляет данные без
записи. Автоматическая синхронизация каталога и запись остатков ещё не включены.
Полный пакет 21 товара получен, соответствия всех трёх складов подтверждены.
Ручное применение цен и вариантов реализовано и выполнено для всех 21 товаров:
232 характеристики связаны с 1С. Из 15 старых несопоставленных вариантов 14
получили точечные привязки, «тёмно шоколадный» 1351 оставлен без привязки по
решению владельца проекта. Импорт остатков и проверка резервов — следующий этап.
Ручная команда для этапа цен и вариантов описана в [ONEC_CATALOG_SYNC.md](ONEC_CATALOG_SYNC.md).
Количество из неизвестных складов и отрицательные остатки не считаются доступным
для продажи запасом. Нельзя включать все склады только потому, что они пришли в XML.

До рабочего запуска нужны также стабильные связи по ID 1С (не по названию),
повторяемый импорт без дублей, обработка неполных/повторных пакетов, контроль
устаревшего обмена и проверка резервов с учётом параллельных продаж в магазинах.
