# Модуль доставки (СДЭК API v2 и самовывоз Mario Mikke)

- **Дата фиксации:** 17 сентября 2026 года
- **Статус:** Реализован, протестирован (модульные, интеграционные тесты и UI-компоненты), внедрён в checkout.
- **Основание:** Требования первого релиза интернет-магазина Mario Mikke (доставка по Москве и РФ, бесплатная доставка в рамках промо-запуска до конца 2026 года).

---

## 1. Архитектура решения

Модуль доставки Mario Mikke поддерживает три взаимодополняющих сценария оформления:

1. **Самовывоз из флагманских магазинов сети (Москва):**
   - ТЦ «Принц Плаза» (м. Тёплый Стан, ул. Профсоюзная, 129А)
   - ТЦ «Новомосковский» (г. Московский, ул. Хабарова, 2)
   - ТРЦ «Небо» (м. Солнцево, ул. Авиаторов, 3А)
   - Срок готовности к выдаче: 1–2 рабочих дня.
   - Стоимость для покупателя: **0 ₽**.

2. **СДЭК — Доставка до пункта выдачи (ПВЗ и постаматы):**
   - Тариф 136 («Посылка склад-склад»).
   - Интерактивный поиск города РФ с автодополнением и debouncing.
   - Выбор конкретного ПВЗ/постамата с отображением точного адреса, режима работы и ориентировочного срока доставки (в днях).
   - Стоимость для покупателя: **0 ₽** (промо-период запуска).
   - Расчётная стоимость СДЭК сохраняется в метаданных для операционного учёта.

3. **СДЭК — Курьерская доставка до двери:**
   - Тариф 137 («Посылка склад-дверь»).
   - Выбор города РФ и ввод детального адреса (улица, дом, квартира/офис, подъезд, этаж, домофон, комментарий курьеру).
   - Стоимость для покупателя: **0 ₽** (промо-период запуска).

## 2. Реализация в Medusa v2 Backend

### Провайдеры и модули:
- Провайдер cdek-fulfillment (pps/backend/src/modules/cdek/):
  - cdek-pickup (ПВЗ СДЭК)
  - cdek-courier (Курьер СДЭК)
  - mario-mikke-pickup (Самовывоз из магазинов)
- Клиент API v2 (pps/backend/src/modules/cdek/lib/cdek-client.ts):
  - OAuth 2.0 Client Credentials flow с автоматическим кэшированием access_token по TTL.
  - Rate limiting / retry-логика.
  - Полнофункциональный offline fallback режим на случай недоступности или отсутствия боевых API-ключей СДЭК при сборке/тестировании.

### Store API Endpoints:
- GET /store/cdek/cities?query=... — поиск городов РФ по названию и коду региона.
- GET /store/cdek/pvz?city_code=... — список пунктов выдачи заказов и постаматов в городе.
- POST /store/cdek/calculate — динамический расчёт тарифа, сроков и весогабаритных ограничений.
- GET /store/cdek/stores — список собственных магазинов сети Mario Mikke для самовывоза.

## 3. Интеграция с витриной (Next.js Storefront)

- Компонент оформления заказа: src/app/checkout/CheckoutClient.tsx.
- Стили оформления: src/app/checkout/checkout.module.css.
- Клиентская библиотека: src/lib/cdek.ts.
- Селектор способов доставки выполнен в виде переключаемых вкладок (Самовывоз / СДЭК ПВЗ / Курьер).
- Валидация обязательных полей: выбор города и ПВЗ блокирует переход к оплате до полного заполнения данных доставки.
- Метаданные доставки сохраняются в сессию Medusa и передаются в заказ.
