## Что нужно для продолжения

Найти существующую характеристику с ненулевым резервом в рабочей 1С. Получить
строку отчёта с товаром, характеристикой, складом и колонками «Количество»,
«Резерв», «Свободный остаток», затем сразу выполнить синхронизацию. Сверить
полученное количество XML с обоими показателями. Не создавать специальный
резерв в рабочей базе ради проверки. Если резервов нет, по текущему снимку
режимы неразличимы: нужно проверять настройку/алгоритм выгрузки 1С.

Нельзя повторно вычитать резерв, пока не установлено, что он ещё не вычтен в
1С. Склады интернет-продаж: Говорово → Мосмарт, Принц плаза, Авеню. Данные
других складов не использовать. Заказы, оплата и доставка остаются в зоне
работы коллеги; согласовать будущий импорт с существующими резервами Medusa.
